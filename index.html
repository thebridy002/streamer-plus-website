A new home for Minecraft.

Streamer Plus now replaces Minecraft's title screen with Horizon: an illustrated landscape, a big clock with the date, a greeting with your face, liquid-glass buttons that open Minecraft's own screens, and your own skin in 3D. Safety

Your money stays yours.

Streamer Plus watches your back while you stream.

  • Big /pay check: big payments show who and how much before anything is sent. Cancel sends nothing.
  • Silent /pay blocker: stops other mods from sending /pay (and similar commands) that you didn't type or click, and tells you which mod probably tried.
  • Real payments only: it only reads the server's own messages, so a player typing "Steve paid you $1B" in chat can't fake an alert.
  • No logins: it never asks for your password and never touches your Minecraft, Microsoft or Discord account.

Install

Up and running in a minute.

Make a Fabric profile

In Modrinth, Lunar Client or the Fabric installer, make a Fabric profile for 26.3, 26.2 or 1.21.11.

Drop in two files

Put the Streamer Plus file for your version and Fabric API into that profile's mods folder.

Press End

Launch the game and press End (or type /birdmod). A short setup walks you through linking your stream.

Lunar Client: use a Fabric profile on 26.3 and add Fabric API next to Streamer Plus. Close Lunar completely before you replace the file with a new version.

FAQ

Good questions.

Is it safe for my account?

Yes. Streamer Plus never asks for your password and never touches your Minecraft, Microsoft or Discord login. It only reads what the server already shows you, and it never sends money for you. Big /pay commands ask you first.

Can I watch YouTube tutorials while I play?

Yes. Open the Stream page, paste any YouTube or TikTok video link and it plays on a screen in your world (or in a corner of your screen). Great for following a farm or base tutorial step by step.

Which streams can I watch?

Live streams from Twitch, YouTube and TikTok, plus YouTube and TikTok videos. You can watch together with friends in a watch party.

The menu is too big on Auto GUI scale. Can I make it smaller?

Yes. In Themes or Utilities, set Menu size and HUD size. Auto picks a comfortable size for your screen whatever Minecraft's GUI scale is.

How do I open it?

Press End, or type /birdmod in chat. You can change the key in Options › Controls under Streamer Plus.

Which version should I download?

The one that matches your Minecraft version: 26.3, 26.2 or 1.21.11. Each button gives you the file built for that version only. If you play on Lunar Client, use 26.3. The 26.3 build is a beta, so report any bugs in the Discord.

Does it work with Lunar Client?

Yes, on 26.3. Make a Fabric profile in Lunar, add Fabric API next to Streamer Plus, and you're set. Close Lunar before you swap in a new version.

Which servers does Money Alerts work on?

It's made for DonutSMP and understands its payment and tax messages. Other servers work too if they announce payments the same way, like "Name paid you $1M".

Does it work on Mac?

Streams, chat, Money Alerts and everything else work on Windows and macOS. The Spotify page uses Windows' media controls, so it's Windows only for now.

What do "online features" do?

They show badges next to other Streamer Plus users and let watch parties sync through a public relay. You can switch them off in Settings and everything else keeps working.

Where are my settings and stats saved?

On your computer, in the config/birdmod folder of your Minecraft profile. Copy that folder to keep your stats when you move to a new profile.

Why is the download so big?

The video player that shows your stream is built into the mod, so you don't have to install anything else.

How do I check my download?

Each download lists its SHA-256. On Windows, run Get-FileHash on the file in PowerShell and make sure the result matches.
